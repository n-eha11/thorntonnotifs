For ICS H32 or 33 students, thorntonnotifs sends notifications to your phone whenever Professor Thornton releases Reinforcement Exercises and/or Projects by monitoring his coursewide 
announcements on his course website's "Course News" webpage. Clicking on the notification will take you to the course website's "Schedule" page.

Setup
- Download the ntfy app and subscribe to each course's appropriate topic [not released here]. 

Limitations and Future Improvements:
- Updating the baseline file containing announcements currently only checks if a new date was added to the course news table. It does not check the content
of announcement, which means if an existing announcement were modified or two announcements were posted on the same day, a change wouldn't be registered. To
my knowledge, these circumstances don't happen. In case they do, this part of the program could be modified.
- This program extracts the assignment and due date from the "Schedule" page of the course website and only when a new course announcement is made on the 
"Course News" webpage. So, if the due date were to be modified (say, on the individual assignment page) and an announcement is not posted, the user will
not receive a notification.
- Currently, a subscription thread only exists for H32 and in some parts of the program, the H32 information is hardcoded. In the future, this will also
accomodate ICS33.
